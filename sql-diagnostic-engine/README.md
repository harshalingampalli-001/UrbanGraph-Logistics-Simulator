# Enterprise SQL Database Diagnostic & RCA Engine

An automated support tool for analyzing database performance bottlenecks, reviewing active connections, and generating Instant Root Cause Analysis (RCA) reports.

## Tech Stack
- Python (Streamlit, SQLAlchemy, Pandas)[cite: 6]
- PostgreSQL[cite: 6]
- Docker & Docker Compose[cite: 6]

## Quick Start
**Clone the repository:**

**Bash:**
git clone https://github.com/harshalingampalli-001/sql-diagnostic-engine.git
cd sql-diagnostic-engine

**Run with Docker Compose:**

**Bash:**
docker compose up --build
